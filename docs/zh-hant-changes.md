# 繁體中文調整說明

> 本文整理這次對「江山時序」繁體中文介面所做的調整：改了什麼、怎麼改。
> 逐條細節與完整對照表見 [繁體化工作日誌](zh-hant-worklog.md)。

## 摘要

這次在既有轉換器的基礎上，把全站 **12,181 段中文字串、約 12.2 萬字**逐段做了繁體稽核，修正了 **177 條**詞組。重點是讓人名、地名、國名、年號、官職都採用史籍原本的繁體寫法，而不是單純的字對字簡轉繁。另外補上了繁體 README、回歸測試和完整的工作日誌。

## 背景

簡體的一個字，在繁體裡常常對應好幾個字，例如：后／後、干／乾／幹、发／發／髮、历／歷／曆、于／於、并／並／併、台／臺、岳／嶽、曲／麴、准／準。

歷史地圖的內容大量是專有名詞，詞庫難免有遺漏，例如「干隆」沒有轉成「乾隆」、「湖南岳陽」被轉成「湖南嶽陽」、「重大歷史事件」被轉成「重大曆史事件」。

原作者已經建好執行期轉換器（`js/zh_hant.js`，約 600 條詞組），處理了大部分常見的歧義。這次只是在這個基礎上，拿全站的實際內容逐條核對，補上少數還沒處理到的地方。

## 調整原則

1. **不動資料，只補轉換器。** 繁體介面仍然由簡體資料即時轉出，所以簡體版、拼音搜尋和既有測試完全不受影響，日後上游新增內容也會自動有繁體版。
2. **專有名詞以史籍寫法為準。** 依據臺灣教育部《國字標準字體》與通行史籍的繁體寫法。
3. **臺灣用語只做等長替換。** 這樣不會改變字串長度，搜尋結果的位置標記也就不受影響。
4. **每一條修正都有紀錄、有測試。** 對照表寫在工作日誌裡，關鍵案例寫進回歸測試，避免日後退化。

## 如何驗證

```bash
node scripts/validate_atlas.js           # 完整驗證套件（含 CUJ 34 繁體回歸用例）
npm test --prefix scripts/search-pinyin  # 拼音／繁簡雙向搜尋
node scripts/perf_budget.js --check      # 首屏效能預算（zh_hant.js 為延遲載入）
```

也可以直接打開 `?lang=zh-tw` 實際查看，例如 `?year=1415&lang=zh-tw`。
